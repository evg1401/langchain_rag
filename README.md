# RAG

## Структура проекта

```text
.
├── app/              # Сборка RAG-цепочки и загрузка конфигурации
├── chunker/          # Извлечение текста из PDF и подготовка чанков
├── docs/             # Исходные PDF-документы
├── helpers/          # Вспомогательные функции для чанков и JSON
├── http_adapter/     # FastAPI-адаптер и HTTP-эндпоинты
├── qdrant/           # Поиск и загрузка векторных данных в Qdrant
├── qdrant_data/      # Локальное хранилище данных Qdrant
└── ya_llm/           # Интеграция с Yandex Cloud
```

## Переменные окружения

| Переменная | Описание |
| --- | --- |
| `YC_FOLDER_ID` | Идентификатор каталога в Yandex Cloud |
| `YC_API_KEY` | API-ключ в Yandex Cloud |
| `QDRANT_COLLECTION` | Коллекция в Qdrant |
| `DOC_PDF_PATH` | Путь к PDF-файлу |

## Сборка

```bash
docker compose up -d
```

## Запуск

1. Добавьте PDF-файл в директорию `docs`.
2. После сборки создайте коллекцию Qdrant:

   ```http
   PUT http://{host}:6333/collections/QDRANT_COLLECTION
   ```

3. Запустите чанкование:

   ```http
   POST http://{host}:8000/v1/chunker/chunk_pdf
   ```

4. Чтобы открыть чат и авторизоваться в WebUI, перейдите в браузере по адресу `http://{host}:3000`.


В проекте используется облачная языковая модель YandexGPT Lite.

## Результаты

По результатам ручного тестирования на текущем документе:
- На вопросах о фактах, отсутствующих в документе, модель в тестах сообщала, что подтверждение не найдено. Галлюцинаций выявлено не было.
- При запросах с неточными или другими названиями сущностей (например, «ЛК Ozon») модель иногда смешивает факты, хотя ответ опирается на найденный контекст.
- После поиска чанки сортируются по номеру страницы и позиции в странице. Благодаря этому контекст передаётся модели в порядке исходного документа и реже обрывается на границе чанков.

## Ограничения и безопасность

- Документы и контекст запроса передаются в облачный сервис и не содержат чувствительных данных. Защиту конфиденциальных данных необходимо обеспечить на этапе пред обработки документов перед сохранением в БД; перед индексацией конфиденциальные и персональные данные следует удалить или обезличить.
